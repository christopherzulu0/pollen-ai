📝 STEP 1: Add to your .env file
───────────────────────────────────────────────────────────────
Open: .env
Add these 4 lines:

GOOGLE_APPLICATION_CREDENTIALS="./pollenblockchain-firebase-adminsdk-fbsvc-731021d8f2.json"
GOOGLE_CALENDAR_ID="primary"
SUPPORT_TEAM_EMAIL="christopherzulu04@gmail.com"
ENABLE_GOOGLE_CALENDAR=true

Save and close.


🌐 STEP 2: Enable Calendar API
───────────────────────────────────────────────────────────────
1. Go to: https://console.cloud.google.com/
2. Select project: "pollenblockchain"
3. Click: APIs & Services → Library
4. Search: "Google Calendar API"
5. Click: Enable


🔄 STEP 3: Restart Server
───────────────────────────────────────────────────────────────
Press Ctrl+C to stop, then:
npm run dev


✅ STEP 4: Test It
───────────────────────────────────────────────────────────────
1. Open: http://localhost:3000/contact
2. Click: "Schedule Meeting" tab
3. Fill form and submit
4. Look for: "Google Meet link" on confirmation page
