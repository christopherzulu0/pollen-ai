STEP 1: Create Zoom Account (5 min)
───────────────────────────────────────────────────────────────
1. Go to: https://zoom.us/signup
2. Sign up with your email
3. Verify email and complete profile

Free plan is perfect for most meetings!


STEP 2: Create OAuth App (3 min)
───────────────────────────────────────────────────────────────
1. Go to: https://marketplace.zoom.us/
2. Click: "Develop" → "Build App"
3. Select: "Server-to-Server OAuth"
4. Fill in:
   App Name: Pollen Meeting Scheduler
   Description: Automated meetings
   Contact: your-email@example.com
5. Copy these credentials:
   - Account ID
   - Client ID  
   - Client Secret
6. Add Scopes:
   - meeting:write:admin
   - meeting:read:admin
   - user:read:admin
7. Click: "Activate"


STEP 3: Add to .env (1 min)
───────────────────────────────────────────────────────────────
Open your .env file and add:

ZOOM_ACCOUNT_ID="paste_account_id_here"
ZOOM_CLIENT_ID="paste_client_id_here"
ZOOM_CLIENT_SECRET="paste_client_secret_here"


STEP 4: Restart Server (1 min)
───────────────────────────────────────────────────────────────
npm run dev


STEP 5: Test It! (1 min)
───────────────────────────────────────────────────────────────
1. Open: http://localhost:3000/contact
2. Click: "Schedule Meeting"
3. Fill form and submit
4. Look for: "Join Zoom" button

"Missing Zoom credentials"
  → Check .env has all 3 variables
  → Restart server

"Failed to get access token"
  → Verify credentials are correct
  → Check app is "Activated" in Zoom
  → Ensure scopes are added

"Zoom API error"
  → Double-check Account ID
  → Verify Client ID and Secret
  → Check Zoom account is active
